# Quiz Spec

## Inputs

- 一个或多个已就绪文档 ID。
- 题量 5 或 10。
- 单选或简答，至少选择一种。
- 可选章节/知识点。

## Generation

- 只使用所选文档的检索上下文。
- 模型返回 JSON 后校验数量、题型、选项、答案、解析、知识点和真实引用。
- 校验失败时重新生成一次；仍失败则返回 502。

## Grading

- 单选：答案精确匹配 A/B/C/D。
- 简答：关键词重合度高于 0.6 判正确，0.25–0.6 返回自评，低于 0.25 判错误。
- 提交事务同时写入 attempt、answers 和 wrong_items。
